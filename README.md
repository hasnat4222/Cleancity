Overview

CleanCity is a full-stack web application designed to bridge the gap between citizens, municipal cleaning teams, and city administrators. It provides a digital platform where anyone can report garbage dumping in their neighborhood, track the cleanup progress in real-time, and share feedback after the job is done.

CleanCity is a smart web-based garbage management system that helps citizens report waste problems easily and allows city authorities to manage and monitor cleaning activities efficiently.

It connects citizens, workers, and administrators in one platform to make the city cleaner and more organized.

✨ Features

👤 For Users
Report garbage with image upload
Get tracking ID for complaints
Track complaint status anytime
Give review after cleaning

👷 For Workers
Login using team code
View assigned tasks
Upload proof after cleaning

🛠️ For Admin
Manage all complaints
Assign cleaning teams
Monitor progress
Approve completed work

🛠️ Technology Used
Python (Flask)
SQLite Database
HTML, CSS, Bootstrap
Jinja2 Template Engine
